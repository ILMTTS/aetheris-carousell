如果 Python 安裝器出現以上錯誤，請先改用 Microsoft Store 的官方 Python 3.13。Aetheris v78 不再自動下載及反覆執行出錯的 Python EXE 安裝器。

這個畫面本身不足以判斷所有封鎖原因；請保留 Windows 記錄。本工具不會關閉智慧型應用程式控制、Microsoft Defender，或修改系統信任設定。

If the Python installer shows these errors, try the official Python 3.13 package from Microsoft Store. Aetheris v78 no longer downloads and repeatedly runs the failing Python EXE installer.

The dialog alone does not establish every cause. Keep the Windows event logs. Aetheris does not turn off Smart App Control or Microsoft Defender, or change system trust settings.

先安裝官方 Store 版，再繼續Install the official Store package, then continue

  1. 在需要使用工具的 Windows 帳戶開啟 Microsoft Store。
  2. 搜尋 Python 3.13，確認發行者是 Python Software Foundation。官方版本是免費的。
  3. 完成安裝後，回到完整解壓縮的 v78 程序資料夾，再雙擊 一鍵安裝環境.bat。
  4. 看到「驗證成功」後，雙擊同一資料夾的 啟動工具.bat。原有圖片及設定請保留。
  1. Open Microsoft Store using the Windows account that will run Aetheris.
  2. Find Python 3.13 and check that the publisher is Python Software Foundation. The official package is free.
  3. After installation, return to the fully extracted v78 folder and double-click 一鍵安裝環境.bat.
  4. Wait for successful validation, then double-click 啟動工具.bat in the same folder. Keep your existing photos and settings.
