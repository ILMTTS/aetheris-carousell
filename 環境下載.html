環境下載與安裝

尚未安裝環境也可打開本頁。先安裝 Python 和 Chrome，再按下列步驟完成設定。

1. 先準備這兩項

建議 Python 3.13 系列

Python

程式執行環境。本工具要求 Python 3.13 或以上；安裝時請確認發行者為 Python Software Foundation。

Microsoft Store 官方下載備用：Python.org 3.13.17 下載頁
Google 官方穩定版

Google Chrome

用來顯示控制頁及操作 Carousell。電腦已有可用的 Chrome 可沿用，毋須重複安裝。

Google Chrome 官方下載由官方頁面提供適合電腦的安裝版本。

2. 回到程序資料夾完成安裝

  1. 先完整解壓縮程序包不要直接在 ZIP 預覽內啟動。更新舊版時保留圖片、設定和登入資料。
  2. 雙擊 一鍵安裝環境.bat工具會在自己的 .venv 環境內安裝 Pillow、Playwright、所需依賴及 Chromium；等待顯示「驗證成功」。
  3. 然後雙擊 啟動工具.bat環境未齊全時，啟動工具會先開啟這份安裝頁；安裝後再啟動便會進入操作網頁。這份 HTML 不會自行安裝程式。

進階：已有 .venv 時的手動安裝指令

只在已建立 .venv 後使用。在程序資料夾開啟 PowerShell，執行以下指令；一般用戶使用上方批次檔即可。若顯示「應用程式控制原則已封鎖」，重複執行安裝指令不能解除封鎖。

.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium

Windows 封鎖提示

這些官方連結提供下載來源，不代表能解除 Windows 原則封鎖。若 Pillow 或 greenlet 仍被封鎖，請查看工具的環境檢查結果；本頁不會修改 Windows 防護設定。
